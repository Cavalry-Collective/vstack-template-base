Buttons

Exactly one primary (filled) action per view. Labels are verb-first and specific. In-flight feedback stays on the triggering control.

Form field

Data states

Every data-backed screen handles loading / error / empty / success the same way. Empty states are designed, not blank; a load failure is an error state with a retry, never an empty state.
